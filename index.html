About

Nao

Musician / Videographer / Photographer / Web Designer / Engineer

福井県出身。学生時代よりバンド活動を行い、オリジナル楽曲制作・ライブ活動を経験。福井テレビ番組のテーマソング起用や、音楽フェス「ミリオンロック」への出演を経て、ツアーファイナルでは地元ライブハウスで120人規模の自主イベントを企画・開催。

その後、活動を映像・写真・Web領域へと拡大。ウェディング映像、湘南美容クリニックYouTube、MV、ワーナーミュージック関連アーティストのショートMVなどを手がけ、カメラマンとしてもポートレートから企業・イベントまで幅広く対応。

エンジニアとしてはスカパー、LINE、トヨタイムズ、ホットペッパー等の改修・推進に従事。プログラマー / PMとして開発支援を行う。

— 「人生を遊ぶ」をテーマに、技術とクリエイティブを横断した表現・体験づくりを。
